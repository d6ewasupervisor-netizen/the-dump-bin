How to use Survey Admin
  1. Stores shows coverage. Needs assign = nobody covering that store yet.
  2. Weekly path: open Assign from PROD → pick the cycle → Sync with PROD → check names and emails → Assign selected.
  3. One-off: Assign someone else — search a name or type an email, check stores, Assign.
  4. Results is where you read submitted answers, then export CSV / Excel / photos.
  5. To fill out a store yourself, use Store Survey — same page reps use.

How to read and export results
  1. Filter by district, store, and status. Default is submitted surveys only.
  2. Tap a store card to read answers, comments, and photos. Problem answers show in red.
  3. Use Prev / Next to walk stores. Export CSV, Excel, or a photos ZIP — filters apply.
  4. Photo links expire after about 30 days. Download the ZIP if you need a lasting copy.

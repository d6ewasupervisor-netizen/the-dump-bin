SAS Automator update

One download. Put it on the USB stick. Do not leave the zip in Chrome’s default Downloads folder on this laptop.

  1. Plug in the USB stick. Wait until File Explorer shows the drive (example: E: or F:).
  2. Open that drive. Find the folder that already has the automator in it. It is named sas-automator-portable (or the folder you used last time with manifest.json inside). Leave that window open so you can see the path.
  3. In Chrome, click the address bar, type exactly chrome://settings/downloads, press Enter.
  4. Under Location, click Change.
  5. In the folder picker, click the USB drive, then click the sas-automator-portable folder (the one with manifest.json). Click Select Folder. Do not pick the USB root. Do not pick Documents or Downloads.
  6. Come back to this page. Click Download update once. Wait until it says Downloaded. File Explorer should show a zip named like sas-automator-portable-2.8.3.zip inside that same USB folder.
  7. If the zip is missing from the USB folder, stop. Check Chrome’s download shelf. If it went to This PC → Downloads, move that zip onto the USB folder, then delete it from Downloads.
  8. On the USB folder, double-click the zip to open it. Press Ctrl+A (select all). Press Ctrl+C (copy).
  9. Click the USB folder behind the zip (the folder that already has manifest.json). Press Ctrl+V (paste). When Windows asks, choose Replace the files in the destination for every prompt. Do not extract into a new folder named after the zip.
  10. In Chrome, type chrome://extensions, press Enter. Find SAS Retail Automator (Portable). Click the reload circle. Unlock with your pattern.
  11. Go back to chrome://settings/downloads → Change → This PC → Downloads, so later Chrome downloads do not keep going to the USB stick.

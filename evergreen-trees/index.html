Evergreen Christmas Trees

November 2–6. Project 12959.

When

Every shift is on the schedule for Friday, November 6. You can do a store on any day this week, through Friday.

If a store will not be finished by Friday, tell me.

Before you start

The store unboxes the trees and sets them. You do not start until that setup is done. This is a second pass, so the display trees get more attention than the store setup alone.

What you do

  1. Shape and fluff every tree so it looks realistic, reads well from the aisle, and matches the standard of the display.
  2. Report 2 hours for the store. If the work takes more than 2 hours, record why.
  3. Complete the survey. It needs one before picture and one after picture. The pictures need to be clear. They are sent to the client.

Portable automator

One download, on this sign-in only. The zip is the portable extension with vault.enc already inside. After it downloads, this card is gone.

  1. On this computer, click Download once. Save the zip somewhere you will keep, such as Documents. Do not leave it in a temp folder.
  2. Right-click the zip → Extract All. Extract into its own folder. The folder must contain manifest.json and vault.enc side by side. If Extract All nested them inside another folder, use the inner folder that has those two files.
  3. In Chrome, open chrome://extensions. Turn on Developer mode.
  4. Click Load unpacked. Choose that folder. The card name is SAS Retail Automator (Portable).
  5. Open the side panel. Unlock with the same pattern you use on the portable copy at home.
  6. SAS sign-in uses the vault. You do not type the SAS password on this computer. If unlock fails, the pattern is wrong or vault.enc is not in the folder you loaded.
  7. Later code updates come from the extension’s own update, not from this page. This download cannot be repeated. A new one has to be minted from home.
